### About

I build the backend stuff nobody notices until it breaks: auth that doesn't leak, APIs that hold up under load, and systems that recover gracefully when the connection drops.

Give me a problem involving concurrency, consistency, or real-time delivery and I'm hooked.

**Currently building:** [Realtime-Canvas](https://github.com/Shivraj098/Realtime-Canvas), a collaborative editor working through conflict resolution and reconnect/replay over WebSockets.

### Projects

**[AuthStack](https://github.com/Shivraj098/AuthStack)** — [Live](https://auth-stack-client.vercel.app/)
An identity and access management platform implementing OAuth 2.0 with PKCE, TOTP-based multi-factor authentication, JWT session handling, rate limiting, and audit logging. Built to model the security surface a production auth service actually needs to cover, not just the login form.
`OAuth2` `PKCE` `MFA` `JWT` `PostgreSQL`

**[TaskFlow](https://github.com/Shivraj098/task-manager)** — [Live](https://task-manager-ten-lac-95.vercel.app/)
A team task management platform with role-based access control, permission-scoped API endpoints, and realtime synchronization across clients. Built with Next.js, TypeScript, PostgreSQL, and Prisma.
`RBAC` `Realtime Sync` `API Design`

**[Realtime-Canvas](https://github.com/Shivraj098/Realtime-Canvas)** *(in progress)*
A collaborative canvas focused on the hard problems of multi-user editing: operation ordering, concurrent-edit resolution, state persistence, and resumable connections after a client drops and reconnects mid-session.
`WebSockets` `Concurrency Control` `State Recovery`

**[HirePilot](https://github.com/Shivraj098/hirepilot)** *(prototype)*
An AI-assisted recruiting tool covering resume parsing, ATS-fit analysis, resume tailoring, skill-gap detection, and application tracking, backed by PostgreSQL.
`LLM Integration` `Document Processing` `PostgreSQL`
