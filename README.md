**[TaskFlow](https://github.com/Shivraj098/task-manager)** — [Live](https://task-manager-ten-lac-95.vercel.app/)

Includes role-based access, CSRF protection, JWT cookie sessions, and admin moderation tools.  
`MERN` `WebSockets` `Real-time Messaging` `RBAC` `Due Diligence Workflow`

**[Realtime-Canvas](https://github.com/Shivraj098/Realtime-Canvas)** *(In Progress)*  
A collaborative canvas editor engineered for real-world concurrency challenges.  
- **Conflict resolution**: Concurrent edits on the same shape are ordered using Hybrid Logical Clocks and merged per-field.  
- **Authoritative server**: Node.js WebSocket server stamps operations, persists to an append-only SQLite log, and broadcasts updates.  
- **Resilience**: Clients replay only missed ops on reconnect; full test coverage (unit + integration), linting, CI, and production deployment practices.  

`WebSockets` `Hybrid Logical Clocks` `CRDT-like Merging` `State Recovery` `Concurrency Control`

**[HirePilot](https://github.com/Shivraj098/hirepilot)** *(Prototype / Learning Project)*  
An AI-powered recruiting assistant for resume parsing, ATS compatibility scoring, skill-gap analysis, resume tailoring suggestions, and application tracking.  
`LLM Integration` `Document Processing` `PostgreSQL`
